# Malak Jounaid — Professional Portfolio

Static HTML/CSS/JavaScript. No Node.js or npm required.

## Open in VS Code
1. Open this folder in VS Code.
2. Right-click `index.html` → **Open with Live Server**.
3. Edit `index.html`, `styles.css` or `app.js` with Codex; save changes to see them refresh.

## Files
- `index.html`: homepage, cards and modal structure
- `styles.css`: layout, colors, responsive design and animation
- `app.js`: bilingual content and popup interactions

## Before publishing
- Review and correct professional experience descriptions.
- Add approved projects and portfolio examples.
- Add your real contact details and résumé links (currently placeholders).
- Avoid including confidential university or employer material.
